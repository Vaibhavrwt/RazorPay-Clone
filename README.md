Razorpay Clone

A fully responsive Razorpay landing page clone built using HTML, Tailwind CSS, and modern frontend practices.
This project recreates the clean UI and responsive design of the Razorpay website for learning and practice purposes.

🚀 Features
⚡ Fully responsive design
🎨 Styled using Tailwind CSS
📱 Mobile-first layout
🧩 Reusable UI sections/components
🌙 Modern and clean interface
💻 Beginner-friendly project structure
🛠️ Tech Stack
HTML5
Tailwind CSS
JavaScript 
📂 Project Structure
├── index.html
├── src/
│   ├── input.css
│   └── output.css
├── images/
├── js/
└── README.md

⚙️ Installation & Setup
Clone the repository
git clone https://github.com/Vaibhavrwt/RazorPay-Clone.git)
Navigate to the project directory
cd razorpay-clone
Install dependencies
npm install
Start Tailwind CSS build process
npm run dev
Open index.html in your browser
